LUDO FITNESS — PROJETO ANDROID OFFLINE

Este projeto contém uma versão inicial do jogo dentro de um aplicativo Android.
O jogo abre a partir de um arquivo local do próprio aplicativo e não precisa de
internet durante a partida. O projeto não solicita permissão de acesso à internet.

COMO GERAR O APK (precisa de um computador):
1. Instale o Android Studio em um computador compatível.
2. Extraia o ZIP.
3. No Android Studio, escolha Open e selecione a pasta LudoFitness.
4. Aguarde a sincronização do Gradle. Na primeira compilação, o Android Studio
   pode precisar baixar componentes de desenvolvimento pela internet.
5. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Ao terminar, use o link/aviso "locate" do Android Studio para encontrar o APK.
7. Transfira o APK para o celular Android e instale. Talvez seja necessário autorizar
   a instalação de apps dessa fonte nas configurações do aparelho.

IMPORTANTE:
- Depois de instalado, o jogo funciona sem internet.
- Este ZIP é o projeto-fonte Android, não um APK já compilado.
- A versão é um protótipo para trabalho acadêmico; teste as regras antes de usar
  em uma apresentação.
